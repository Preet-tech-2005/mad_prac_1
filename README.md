# Practical-1: Kotlin Programming Concepts

## Objective

To develop Kotlin programs demonstrating fundamental programming
concepts such as variables, data types, type conversion, input/output,
control flow, functions, recursion, arrays, ArrayList, classes,
constructors, operator overloading, and matrix operations.

## Practical Programs

### 1.1 Store & Display Values in Different Variables

Demonstrates different Kotlin data types: - Integer (`Int`) - Double
(`Double`) - Float (`Float`) - Long (`Long`) - Short (`Short`) - Byte
(`Byte`) - Character (`Char`) - Boolean (`Boolean`) - String (`String`)

### 1.2 Type Conversion

Demonstrates conversion between data types: - Integer to Double - String
to Integer - String to Double

### 1.3 Scan Student Information

Accepts and displays student information such as: - Name - Enrollment
number - Branch - Semester - Age

### 1.4 Check Odd or Even Number

Uses the modulus operator (`%`) and an `if` expression to determine
whether a number is odd or even.

### 1.5 Display Month Name

Uses Kotlin's `when` expression to display the month name according to a
number from 1 to 12.

### 1.6 User-Defined Function

Creates functions to perform: - Addition - Subtraction -
Multiplication - Division

### 1.7 Factorial Calculation with Recursion

Calculates the factorial of a number using a recursive function.

### 1.8 Working with Arrays

Demonstrates: - `Arrays.deepToString()` - `contentDeepToString()` -
`IntArray.joinToString()` - `range` - `downTo` - `until` - Array
traversal - Sorting without built-in functions - Sorting using the
built-in `sort()` function

### 1.9 Find Maximum Number from ArrayList

Creates an `ArrayList` of integers and finds the maximum value using a
loop.

### 1.10 Class and Constructor Creation

Creates a `Car` class with properties: - Type - Model - Price - Owner -
Miles driven

It also demonstrates constructors, object creation, and functions for
displaying car information, original price, and current price.

### 1.11 Operator Overloading and Matrix Operations

Creates a `Matrix` class and demonstrates: - Matrix addition - Matrix
subtraction - Matrix multiplication - Operator overloading using `+`,
`-`, and `*` - Custom `toString()` implementation

## Technologies Used

-   **Language:** Kotlin
-   **IDE:** Android Studio / IntelliJ IDEA
-   **Platform:** JVM

## Basic Kotlin Concepts Covered

  Concept                 Kotlin Example
  ----------------------- ---------------------------
  Variable                `val`, `var`
  Input                   `readLine()`
  Output                  `println()`
  Condition               `if-else`
  Multiple conditions     `when`
  Function                `fun`
  Recursion               Function calling itself
  Array                   `IntArray`
  Collection              `ArrayList`
  Class                   `class`
  Object                  `Car(...)`
  Constructor             Primary constructor
  Operator Overloading    `operator fun plus()`
  String Representation   `override fun toString()`

## How to Run

1.  Open the project in Android Studio or IntelliJ IDEA.
2.  Create/open a Kotlin project.
3.  Create a Kotlin file for the required practical program.
4.  Copy the corresponding program into the file.
5.  Run the `main()` function.
6.  Enter input when requested and observe the output in the console.

## Learning Outcomes

After completing this practical, the student will be able to:

-   Declare and use different Kotlin data types.
-   Perform type conversion.
-   Take input from the user.
-   Use conditional statements and `when`.
-   Create and call user-defined functions.
-   Understand and implement recursion.
-   Work with arrays and ArrayList.
-   Sort arrays using different approaches.
-   Create classes, constructors, and objects.
-   Understand operator overloading.
-   Perform basic matrix operations in Kotlin.

## Conclusion

This practical provides a foundation in Kotlin programming by covering
basic syntax, data types, control flow, functions, collections, arrays,
recursion, object-oriented programming, operator overloading, and matrix
operations.
